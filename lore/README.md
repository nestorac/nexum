# Lore de Nexum

Esta carpeta contiene todo el worldbuilding y la fuente de verdad del universo Nexum.

Aquí viven los documentos de cosmología, personajes, lugares, facciones, sistemas, filosofía y cualquier material de ambientación. Cualquier cambio en el lore se hace primero aquí y luego se refleja en los juegos, relatos o manga.
