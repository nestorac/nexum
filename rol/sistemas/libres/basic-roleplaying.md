# Basic Roleplaying (BRP)

## Descripción
Sistema genérico de Chaosium basado en porcentajes (d100). Base de juegos como *La Llamada de Cthulhu*.

## Por qué encaja con Nexum
Sólido para investigación, misterio y partidas donde el éxito no está garantizado. Fácil de adaptar a entornos de tensión y descubrimiento gradual.
